## 🚀 Running Locally

Because this project is built with Vanilla HTML, CSS, and JS, running it is incredibly simple:

1. Clone the repository:
   ```bash
   git clone https://github.com/shamikhz/portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in your favorite web browser, or use an extension like VSCode Live Server.
